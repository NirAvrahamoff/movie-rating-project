# Movie Rating Project

End-to-end project for predicting IMDb movie ratings.

## Structure

| Part | Description |
|------|-------------|
| part1-data-mining | Data collection — scraping 5,000 movies from IMDb, Wikipedia, OMDb |
| part2-ml-model | ML model — Random Forest, Elastic Net, Decision Tree |
| part3-web-app | Flask web app — predicting ratings via UI |
